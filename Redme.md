# Tech & EDM Festival 2026 🎧

Este es un proyecto web moderno desarrollado para un festival de música electrónica. El objetivo principal fue implementar un flujo de trabajo profesional utilizando herramientas de automatización para la optimización de recursos y estilos.

## 🚀 Tecnologías y Herramientas

* **HTML5 & CSS3**: Estructura y diseño responsivo.
* **SASS**: Preprocesador de CSS para un código más organizado y mantenible.
* **Gulp**: Automatizador de tareas para optimizar el flujo de trabajo.
* **JavaScript**: Funcionalidad interactiva del sitio.
* **Sharp**: Procesamiento avanzado de imágenes para mejorar el rendimiento.
